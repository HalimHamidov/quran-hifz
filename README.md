# Quran Hifz | 23 года с Кораном

Статическая платформа спокойного заучивания и постоянного повторения Корана.
**Постоянство. Терпение. Повторение.**

Сура 73: [карточки аятов 1–5](surahs/073-al-muzzammil/) с отдельными иллюстрациями, арабским текстом и краткими пояснениями по тафсиру ас-Саади. Картинки также доступны в режиме заучивания; аяты 6–20 не иллюстрированы.

В каждой из пяти карточек доступен режим «Арабский язык»: слова, грамматика, формы слов, учебные фразы, мнемоника и таджвид. Пословная грамматика сверена с Quranic Arabic Corpus; слова выводятся из исходного Tanzil без изменения огласовок.

Разделы «Слова» и «Мнемоника» также содержат таджикские учебные подсказки. Словарные основы проверены в Vazhaju, ссылки ведут к выбранным значениям слов; общий арабский корень отмечен отдельно от смысловой ассоциации. Это авторский учебный материал, не опубликованный перевод Корана.

- Сайт: https://halimhamidov.github.io/quran-hifz/
- Репозиторий: https://github.com/HalimHamidov/quran-hifz
- Исходный `HalimHamidov/mulk` не изменяется.

## Запуск

Нужен Python 3. Для команд `npm` и автоматических тестов нужен Node.js 22+; зависимостей приложения нет.

```powershell
cd F:\Code\67mulk\quran-hifz
npm start
```

Открыть http://127.0.0.1:4175/quran-hifz/ . Если порт занят, используйте `python -m http.server 4176 --directory ..`.
Открытие `index.html` через `file://` не поддерживается: данные загружаются через HTTP.
Сборка не требуется. Все пути относительные, включая manifest и service worker; поддерживается `/quran-hifz/`.

## Что работает

- Сура 74 «Аль-Муддассир»: [аяты 1–10](surahs/074-al-muddassir/) по порядку мусхафа, десять отдельных реалистичных изображений и дословный смысловой перевод Шамиля Аляутдинова, предоставленный пользователем. Авторские пояснения показаны отдельно; общий диапазон 8–9 сохранён. Смысловые подсказки и условные образы отделены от пояснений. Доступны общий прогресс, полноэкранный просмотр и офлайн-кеш. Промпты: `data/al-muddassir-visual-plan.json`. Аяты 11–56 здесь не иллюстрируются.

- 114 сур, 6 236 аятов Tanzil Uthmani 1.1, оригинал хранится локально без изменений.
- Поиск, порядок мусхафа, традиционный порядок начала ниспослания и отдельный личный порядок 96 → 74 → 68 → 73 → 1.
- Все 56 аятов Аль-Муддассир, пять смысловых блоков, заметки к первым семи аятам, собственные символические иллюстрации и полноэкранная галерея.
- [Аль-Аляк — визуальная страница](https://halimhamidov.github.io/quran-hifz/surahs/096-al-alaq/): 19 отдельных карточек и 19 уникальных фотореалистичных изображений по смыслу каждого аята. Оформление по примеру Аль-Мульк: золотая рамка, кремовое поле, арабский оригинал и круглая деталь рядом с авторской подсказкой памяти. Полноэкранная навигация, аудио, счётчики и проверенный фонд общие с тренажёром. Перевод смыслов Шамиля Аляутдинова добавлен из предоставленного пользователем текста, со всеми скобочными пояснениями и ссылками на источник.
- Аль-Мульк в общем читателе и все пять прежних версий с изображениями в `surahs/067-al-mulk/legacy/`.
- Самостоятельные повторения, независимые прослушивания, исправление счётчика, скрытие текста/пояснения, проверка наизусть, ошибки, соединение соседних аятов.
- Длинные аяты: ручная разметка после проверки учителем, сверка частей с оригиналом, отдельные счётчики частей и соединённого аята. Программа не определяет допустимость остановок.
- Новое заучивание можно приостановить независимо от муроджаа.
- Весь фонд памяти распределяется по длине текста на 7, 14, 30 или 1–365 дней, с сохранением порядка внутри сур. Интервальные проверки: 1/3/7/14/30 дней; ошибки ускоряют проверку.
- Просроченные интервальные проверки включаются постепенно в пределах бюджета времени. Новый круг после пропуска сохраняет весь фонд и журнал, не складывает пропущенные дневные части.
- Аль-Хусари Mu’allim или вручную выбранный Murattal: аят/диапазон, повтор, пауза, 0.75×/1×/1.25× с сохранением высоты голоса.
- Версионированное локальное хранение, проверяемый импорт/экспорт JSON, защита сброса, синхронизация вкладок через событие storage.
- 23-летняя историческая шкала, отдельные категории A/B/C/D для события и датировки. Календарная сетка — приблизительная реконструкция, не точная история каждого аята.
- График размеров 114 сур справа налево, статистика повторений за 7/30 дней и личные учебные годы.
- Адаптивная мобильная вёрстка, клавиатурная навигация, reduced motion, локальный арабский шрифт Amiri.
- PWA: после первого полного открытия оригинал, интерфейс и новые иллюстрации доступны офлайн. Аудио и внешние источники требуют сети. Прежние версии имеют отдельный service worker.

## Архитектура

`index.html` — оболочка, `assets/js/app.js` — hash-маршрутизация и UI. Отдельные модули: `progress.js`, `hifz.js`, `parts.js`, `murajaah.js`, `audio.js`, `history.js`. Статические JSON находятся в `data/`; новые SVG и локальный шрифт — в `assets/`.

`localStorage['quran-hifz:v1']` хранит настройки, индивидуальные записи аятов, счётчики соединений, разметку частей, дневной журнал муроджаа и активность. Секретов и серверной учётной записи нет. Для будущего облачного транспорта предусмотрены версия схемы и проверяемый JSON; сама синхронизация между устройствами не реализована.

Для многолетнего использования подробные списки повторённых аятов и дневных заданий хранятся только за сегодня/вчера; более старые занятия сохраняются как дневные числовые итоги. Весь фонд памяти, даты проверки, ошибки и счётчики каждого аята сохраняются. Статистика за неделю/месяц использует итоги. Старые резервные копии автоматически получают этот формат при проверяемом импорте; полная история отдельных дневных списков после уплотнения не хранится.

## Проверки

```powershell
npm test
npm run verify
```

Первая команда проверяет бизнес-логику на `node:test`; вторая — все арабские строки относительно исходной загрузки Tanzil, контрольные суммы, количество аятов и сохранность перенесённых файлов.

Повторный браузерный smoke-тест (изолированная сессия, не реальные пользовательские данные):

```powershell
npx --yes --package @playwright/cli playwright-cli -s=hifz-qa open http://127.0.0.1:4175/quran-hifz/#surah/74/1 --browser chrome
npx --yes --package @playwright/cli playwright-cli -s=hifz-qa run-code --filename scripts/browser_qa.cjs
npx --yes --package @playwright/cli playwright-cli -s=hifz-qa goto http://127.0.0.1:4175/quran-hifz/#surah/74/1
npx --yes --package @playwright/cli playwright-cli -s=hifz-qa run-code --filename scripts/browser_audio_qa.cjs
```

Первый скрипт требует новой пустой сессии; второй продолжает её, проверяет реальное сетевое аудио и сохранение частей. Артефакты — `output/playwright/`, не публикуются в git. Для повторного прогона создайте новую сессию. Встроенный браузер Codex в исходной среде был недоступен; проверка выполнена изолированным Chrome через Playwright CLI.

## Добавление суры и материалов

Для новых учебных карточек применяйте полный стандарт ниже. Следующие технические инструкции также используются при точечных изменениях существующих материалов.

Все арабские суры уже есть: не вводите аяты вручную. Для редакционного наполнения добавьте запись в `scripts/build_content.py` и `data/translations.json`: ссылку на разрешённый перевод, самостоятельные заметки и смысловые блоки `{from,to,title,explanation,visual}`. Не выдавайте заметку о блоке за дословный перевод отдельного аята. Новые суры используют общий читатель, код не копируется.

Для иллюстрации добавьте собственный или лицензированный файл в `assets/images/`, зафиксируйте автора и условия в `docs/RIGHTS.md`, подключите имя в блоке. Не изображайте пророков; арабскую каллиграфию не генерируйте. Новые изображения также внесите в `service-worker.js`.

Для аудио проверьте чтеца, риваят, соответствие каждому аяту и условия встраивания. В `audio.js` задаётся шаблон адресов. Переключатель Murattal — явный запасной вариант, не скрытая подмена записи. Сначала проверяйте HTTP-ответ, затем реальное декодирование и воспроизведение браузером. Не размещайте MP3 в репозитории без разрешения.

Для исторического события добавьте источник в `sources.json` и событие в `historical-events.json`: участники, связанные аяты, категория достоверности события, отдельная категория/оговорка датировки. Не выводите год полной суры из традиционного порядка первых откровений. Если даты нет — «Точная дата не установлена». Учебные годы и исторические годы не смешиваются.

Обновление исходных данных:

```powershell
python scripts/import_data.py
python scripts/build_content.py
npm run verify
npm test
```

Импорт сначала заменяет метаданные исходными, `build_content.py` возвращает русские названия и редакционные записи. Проверяйте diff и уведомление Tanzil. Не изменяйте арабский оригинал; для исправления обновляйте его из источника. `data/provenance.json` фиксирует SHA-256 загрузок. Особенность официального текстового экспорта: перед первым аятом большинства сур находится басмала; она сохранена как в источнике и не добавляет аят в принятую систему счёта. В интерфейсе басмала отделена строкой от первого аята; в Аль-Фатихе остаётся аятом 1, в Ат-Таубе отсутствует. История, смыслы и визуальные карточки Аль-Аляк открываются одним пунктом.

## Стандарт учебных карточек для любой суры

### Когда и в каком объёме применять

Просьба «оформи суру», «создай карточки» или «продолжи учебные материалы» означает полный комплект из следующих разделов. Не нужно ждать отдельного промпта на арабский язык, таджикские значения, мнемонику или тафсир. Для небольшого исправления уже готовой страницы этот стандарт не расширяет объём задачи.

Сначала зафиксируйте номер суры и диапазон. Используйте явно заданный диапазон либо согласованный в текущей задаче. Если диапазон не указан, берите аяты 1–5, а для более короткой суры — все её аяты; сообщите это решение без остановки работы. Запрос всей суры означает все её аяты. Не добавляйте материалы за пределами задания и не отмечайте остальные аяты как оформленные. При восстановлении сначала проверьте имеющиеся файлы и историю Git; создавайте заново только отсутствующие или неподходящие изображения.

### Арабский оригинал, перевод и тафсир

1. **Арабский оригинал.** Все 114 сур уже находятся в `data/ayahs.json`. Выводите текст и слова из этих данных без изменения символов, огласовок и порядка. Басмалу отделяйте средствами `splitBasmala`, учитывая Аль-Фатиху и Ат-Таубу; не включайте её слова в пословный разбор другого первого аята. Используйте читаемый арабский шрифт, `lang="ar"`, `dir="rtl"` и достаточно места для огласовок.
2. **Русский перевод смыслов.** Предпочтение проекта — предоставленный текст Шамиля Аляутдинова / Umma.ru, если пользователь не выбрал другой источник. Сохраняйте его дословно, вместе со скобками, примечаниями и сносками. Общий перевод нескольких аятов оставляйте общим и подписывайте диапазон. Если текст не предоставлен и право его размещения не установлено, показывайте ссылку и отметку «Локальный перевод не добавлен»; это не блокирует создание остальных материалов. Не сочиняйте текст от имени переводчика.
3. **Ключевой смысл / тафсир.** Для каждого аята прочитайте соответствующее объяснение ас-Саади и составьте краткое самостоятельное изложение. Укажите автора тафсира, точный диапазон, ссылку и подпись «краткое изложение, не дословная цитата». Не приписывайте ас-Саади неподтверждённые детали. Если источник толкует аяты совместно, сохраните это указание. Другой источник используйте по просьбе пользователя либо с явным объяснением замены.
4. **Раздельные слои.** Арабский аят, опубликованный перевод, авторский пересказ тафсира, учебный языковой пример и мнемоническая ассоциация должны быть визуально и текстово различимы. Словарное значение не заменяет контекстный перевод, а картинка не служит доказательством толкования.

### Иллюстрации и карточка аята

На каждый аят нужен отдельный файл и один понятный смысловой якорь. Соседние картинки должны различаться сценой или действием, сохраняя общий стиль: реалистичные материалы, тёплый свет, кремовые карточки, золотые акценты. Полная инструкция для изображений: [AYAH_VISUAL_PROMPT.md](docs/AYAH_VISUAL_PROMPT.md).

Изображения не содержат арабского текста, переводов или случайных надписей: проверенный текст добавляется HTML. Не изображаются Аллах, пророки и ангелы; сокровенное передаётся только косвенными, обозначенными как условные ассоциациями. Не выдавайте иллюстрацию за историческую реконструкцию. Сохраняйте индивидуальные промпты и происхождение изображений, осматривайте результат, добавляйте осмысленный `alt` и оптимизированный WebP. Условия использования материалов фиксируйте в [RIGHTS.md](docs/RIGHTS.md).

Карточка содержит номер, иллюстрацию, арабский текст, доступный перевод и отдельный ключевой смысл. Доступны крупный просмотр, переходы по аятам и переход к общему тренажёру для аудио и повторений. Связывайте визуальную страницу с маршрутом `#surah/S/A`; показывайте соответствующую картинку в тренажёре только внутри оформленного диапазона.

### Режим «Арабский язык»

У каждого аята нужны кнопка «Арабский язык →» и переключатель «Карточка / Арабский язык». Обязательны все шесть разделов:

| Раздел | Что включить |
| --- | --- |
| Слова | Все слова аята по порядку: неизменённое арабское слово, русское и таджикское контекстные значения, приставки/суффиксы, корень там, где он применим, грамматическая функция и ссылки на источники. |
| Грамматика | Короткое объяснение конструкций именно этого аята: обращение, повеление, местоимения, падежи, согласование и другие фактически присутствующие явления. |
| Формы слов | Проверенные формы и семейства выбранных слов. Различайте однокоренные формы, синонимы и антонимы; не представляйте их одной категорией. |
| Фразы | Собственные понятные примеры на литературной фусхе, русский смысл, объяснение связи с аятом и новых слов. Подпись: учебные примеры, не аяты и не тафсир. |
| Мнемоника | Единый маршрут по заданным аятам, сцена каждого аята, привязки к словам, таджикская сцена и словарные мостики. Поясняйте, как образ помогает вспомнить смысл и порядок. |
| Таджвид | Проверенные ключевые места в данном аяте: конкретный фрагмент, правило, условия соединения и отдельная остановка в конце. Укажите чтение Хафс от Асыма, путь аш-Шатыбийя, и источник. |

Пословную морфологию проверяйте в [Quranic Arabic Corpus](https://corpus.quran.com/): ссылка на аят содержит его номер, ссылка на слово — `(S:A:W)`. Не переносите корень, форму, источник или правило таджвида из образца другой суры. При смене аята сохраняйте режим и выбранный раздел; при открытии новой карточки начинайте со «Слов». Проверяйте навигацию, закрытие, клавиатуру и сброс внутренней прокрутки к началу нового материала. На телефоне длинный разбор должен удобно прокручиваться без горизонтального переполнения и обрезания текста.

Таджвид не является автоматической проверкой произношения. Длительности задаются в харакатах, не секундах; не смешивайте правила разных путей чтения. Отдельно учитывайте чтение с предыдущим аятом и начало после остановки: например, начальная шадда может относиться к соединению. Не назначайте правило только по внешнему сходству букв.

### Таджикские значения и Vazhaju

Таджикская часть обязательна для новых полных комплектов. Добавляйте контекстные значения **всех слов**, а не только нескольких удобных заимствований. Для каждого аята создавайте также отдельную таджикскую сцену и включайте её в общую цепочку памяти. Используйте `lang="tg"`; таджикские буквы и диакритику сохраняйте.

Порядок проверки слов в [Vazhaju](https://vazhaju.tj/):

1. Найдите словарную основу, прочитайте статью и выберите подходящее значение. Проверьте часть речи, арабское/персидское написание и наличие омонимов. Одной похожей кириллицы недостаточно.
2. Откройте прямую ссылку вида `/word/слово/идентификатор` и убедитесь, что она ведёт к нужной статье. Не выдумывайте идентификаторы и не используйте одну общую ссылку вместо источника конкретного слова.
3. Сохраните основу, краткое изложение выбранного значения, прямой URL и дату реальной проверки. Покажите ссылку рядом с таджикской подсказкой. Для словосочетания можно указать несколько словарных основ.
4. Грамматические окончания, местоименные сочетания и контекстный смысл оформляйте как авторские учебные подсказки. Не утверждайте, что словарь содержит готовый перевод аята. Полный опубликованный таджикский перевод добавляется только из отдельного проверенного и разрешённого источника, с авторством.
5. Если статья не найдена, не приписывайте её словарю. Подберите проверенный смысловой эквивалент. Если это невозможно или сайт недоступен, пометьте материал как неподтверждённый, сообщите ограничение и продолжайте независимые части задачи. Не отмечайте непроверенное как проверенное. При ограничении запросов снижайте частоту, не запускайте массовые повторные обращения.

Приоритет мнемонических мостиков:

- **Арабское заимствование / общий корень.** Сначала ищите известное таджикское слово с подтверждённым арабским происхождением. Покажите корень и различие форм: `قُمِ` — повеление, «қиём» — существительное; `رَتِّلْ` и `تَرْتِيلًا` связаны с «тартил».
- **Смысловая ассоциация.** Если подходящего заимствования нет, используйте понятный таджикский перевод или предмет: «ҷома / кӯрпа» помогает вспомнить закутавшегося, но не имеет общего корня с `مُزَّمِّل`.
- **Звуковая подсказка.** Допустима только как явно обозначенная авторская ассоциация; она не доказывает происхождение или значение и не заменяет правильное арабское чтение.

Проверенные примеры выбора значений: «қиём I» — стояние, не сахарный сироп; «сақил I» (`ثقیل`) — тяжёлый, не «сақил II» (`صقیل`, отполированный); «ё» — союз «или», не название буквы и не обращение. В `قَوْلًا` выбирается «слово, речь», а не автоматически бытовое «обещание». Примеры служат ориентиром проверки, а не готовыми универсальными вставками для всех сур.

### Когда комплект готов

- Диапазон и число карточек совпадают с запросом; нет пропущенных аятов, общих файлов вместо разных изображений и материалов за пределами диапазона.
- Арабский оригинал совпадает с Tanzil; пословные карточки охватывают все слова. Предоставленный перевод не переписан, совместные диапазоны и сноски сохранены.
- У тафсира, морфологии и таджвида есть проверяемые источники; у всех таджикских подсказок — ссылки на проверенные основы, у общих корней — обоснованная связь с соответствующим арабским словом.
- Все шесть разделов содержательны для каждого аята. Кнопки, переходы и сохранение выбранного раздела работают; мобильная версия читается, картинки действительно декодируются в браузере.
- Проверены состав офлайн-кеша и доступность новых локальных материалов без сети после загрузки. Внешние словари и аудио не называются офлайн-доступными.
- Выполнены `npm test`, `npm run verify` и `git diff --check`; если в системе нет команды `python`, проверку Tanzil запускайте как `python3 scripts/verify_data.py`. Не скрывайте ошибки и непроверенные ограничения.
- Для исправлений только документации проверены согласованность правил, ссылки и `git diff --check`; повторный прогон тестов приложения не требуется.
- Если публикация разрешена в текущей задаче, дождитесь успешной проверки и развёртывания GitHub Actions, затем проверьте живую страницу и новые файлы GitHub Pages. Наличие файлов в локальном каталоге или даже коммита не означает, что они появились на боевом сайте. Сохранённые правила не заменяют разрешение на публикацию будущей задачи.

## Известные ограничения

- Подробные исторические события первой редакции: начало откровений и хиджра. Другие годы честно помечены как ненаполненные; 23 кнопки не означают 23 полностью исследованных годовых хроники.
- Подробные смысловые блоки и иллюстрации созданы для 96, 74 и 67; остальные суры используют общий читатель и требуют редакционного наполнения.
- Для Аль-Аляк и аятов 1–10 Аль-Муддассир добавлен точный пользовательский текст перевода Umma.ru; для остальных аятов предоставлены ссылки. Независимая проверка видео методики не удалась; точные числа приведены по описанию из задания, не как установленная цитата автора.
- Правильность чтения проверяет человек; приложение не распознаёт речь и не оценивает таджвид. Разметка частей считается проверенной только по подтверждению пользователя о работе с учителем.
- План по длине текста сохраняет порядок аятов, но не обладает экспертной разметкой всех смысловых блоков. Оценка времени приблизительна.
- Лицензия на перераспространение MP3 EveryAyah отдельно не установлена. Используется прямое потоковое воспроизведение; офлайн-аудио отсутствует.
- Права и надписи исходной пользовательской галереи Аль-Мульк независимо не переаттестованы; новая платформа сохраняет её отдельно от новых собственных иллюстраций.

План дальнейшего наполнения: 68 → 73 → 1, затем остальные суры в общем формате. Для каждой: источники → самостоятельные пояснения → проверенные иллюстрации → аудиопроверка → мобильная и текстовая проверка. Новые исторические записи добавляются только с проверенными ссылками.

Полный статус требований и результаты: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Права: [docs/RIGHTS.md](docs/RIGHTS.md).

### Арабский язык по 74:1–10

Под каждой карточкой нажмите «Арабский язык: слова и фразы»; в увеличенном просмотре есть переключатель «Карточка / Арабский язык». Для каждого из десяти аятов доступны шесть вкладок: слова (все 27 слов исходника с разделением приставок и суффиксов), грамматика, формы слов, бытовые фразы (21 пример), мнемоника и таджвид. Указаны корни, контекстные значения, новые слова и ссылки на морфологию Quranic Arabic Corpus. Примеры написаны на современной литературной фусхе, не на конкретном разговорном диалекте; они отделены от аятов и точного перевода Шамиля. Учебные окончания не заменяют изучение остановок и таджвида. Разбор открывается без прокрутки, стрелки сохраняют выбранную вкладку. Данные: `data/al-muddassir-language.json`; доступны офлайн.

В тренажёре кнопка «Следующий аят →» доступна и сверху, рядом с выбором аята, и внизу. На последнем аяте обе позиции ведут к муроджаа.

### Мнемоника по первым десяти аятам

В режиме «Арабский язык» вкладка «Мнемоника» содержит 27 образных опор для слов, таджикский смысловой мостик у каждого аята и единый маршрут: покрывало → скамья → горизонт → вода → выход → хлеб → сад → Горн → камень → ворота. Нажатие на этап открывает соответствующий аят, сохраняя вкладку. Ассоциации авторские; таджикские слова не являются арабской транскрипцией. Цепочка охватывает 1–10 из 56 аятов, а не всю суру; образы сокровенного условны.

В языковом разборе 74:1–10 доступна вкладка «Таджвид»: ключевые места чтения Хафс (аш-Шатыбийя), выделенные буквы, отдельные подсказки для остановки и памятка по ихфа, идгаму, изхару и иклябу. Это учебные подсказки, не автоматическая проверка чтения; длительности сверяют с чтецом и учителем. Доступно офлайн.

Таджикские подсказки в «Мнемонике» прежде всего используют арабские заимствования (Рабб, кабир, тоҳир, сабр) и общие корни. Отличия формы аята поясняются; смысловой перевод и простое звуковое сходство обозначены отдельно. Ссылки на словарные источники находятся рядом с подсказкой.

В мнемонике 74:9 используются «явм» (день) и «асир» (عسير, трудный). Отдельно поясняется отличие от أسير — «пленник»: похожая кириллица не означает одинаковые арабские буквы или корни.

Мнемоника 74:10 связывает таджикское «ясир» (يسير, лёгкий) с «ғайр»: غَيْرُ يَسِيرٍ — «нелёгкий», в продолжение عسير — «трудный» из 74:9.

В таджвиде 74:3 слово فَكَبِّرْ показано отдельно: выделена بِّ, пояснены шадда, короткие гласные и мягкая رْ; второй пример не повторяет وَرَبَّكَ.

В «Ключевом смысле» каждой карточки 74:1–10 размещено краткое авторское изложение соответствующего пояснения ас-Саади со ссылкой на полный текст. Для совместно толкуемых аятов указан диапазон источника. Это не дословная цитата; перевод Шамиля сохранён отдельно.

Ас-Саади также указан во вступлении страницы74:1–10 и описании источников; там есть ссылка на полный тафсир и пояснение о кратком изложении.
